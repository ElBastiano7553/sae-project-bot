# Dossier `knowledge/` : notes de l'équipe pour `/ask`

Déposez ici des fichiers `.md` ou `.txt` qui décrivent le projet : résumé du sujet de
la SAE, règles de l'équipe, conventions de code, décisions importantes, comptes rendus…
`/ask` y cherche les passages qui correspondent à la question et les transmet à l'IA,
qui doit **citer** ses sources et dire quand elle ne trouve pas la réponse.

- Un titre Markdown (`#`, `##`…) découpe le fichier en passages : un titre clair par sujet
  aide la recherche.
- Les fichiers sont relus à chaque question : pas besoin de redémarrer le bot.
- **Aucun secret** (mot de passe, token, clé) ne doit être écrit ici : ces fichiers sont
  versionnés avec le code et envoyés à l'IA. Le bot masque ce qui ressemble à un secret,
  mais ce filet de sécurité ne remplace pas la prudence.
- Ce fichier `README.md` n'est pas utilisé comme source.

Sources consultées en plus de ce dossier : `config/planning.toml`, `config/links.toml`,
les messages permanents (`content/messages/`) et la documentation du bot (`README.md`, `docs/`).
